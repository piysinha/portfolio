# Portfolio

Piyush Sinha's public portfolio. It presents their work to hiring managers, engineering peers and prospective clients, and invites them to get in touch.

## Language

### Audience

**Visitor**:
Anyone reading the site. The site serves three kinds: hiring managers or recruiters, engineering peers, and prospective freelance clients.
_Avoid_: User, customer

### Work

**Project**:
A concrete thing Piyush built, usually with a public repository or live link.
_Avoid_: Work item, portfolio piece

**Case study**:
A written account of a problem Piyush solved, with employer and client details anonymised. Detailed accounts of employer work appear only as Case studies; headline career results may appear elsewhere, such as on Home.
_Avoid_: Project write-up, story

### Quality

**Test run**:
One execution of the site's own Playwright suite, together with its report and traces.
_Avoid_: Build, job, pipeline

**Gate run**:
A Test run of the full suite against a preview deploy. Promotion to production happens only if it passes.
_Avoid_: CI run, pre-deploy tests

**Smoke run**:
A short Test run against the live production site, done after promotion. It may fail, and a failure is shown publicly.
_Avoid_: Health check, monitoring run

**Quality dashboard**:
The page that shows Visitors the latest Gate run and Smoke run, with links to their full reports and traces.
_Avoid_: Test results page, live tests

### Contact

**Enquiry**:
A message a Visitor sends through the site's contact form.
_Avoid_: Lead, submission, contact request
